Credo

OpenRouter API key & credit manager — Android, iOS, macOS and Web

Credo is a free, open-source utility for people who build with OpenRouter. Instead of opening the web dashboard to check your remaining credits, Credo shows the balance, daily / weekly / monthly usage and an estimated burn rate right on your desktop or phone. Your API key never touches a third-party server: it stays encrypted in the system Keychain (iOS/macOS) or the Android Keystore.

Download the Android APK Open the web app Source code on GitHub

Highlights

  • Secure key storage — encrypted with platform-native vaults (Keychain / Android Keystore); no servers, no telemetry.
  • Real-time credit monitoring — remaining credits and total balance at a glance.
  • Usage breakdown — daily, weekly, monthly and all-time API usage.
  • Burn-rate estimation — estimated days of credit left at your current pace.
  • Low-balance alerts — warning banners at 20% and 5% of your balance.
  • Material 3 theming — dark, light or follow the system.
  • JSON export — one-tap backup of credit snapshots and key metadata.
  • Four platforms — Android, iOS, macOS and the web from one Flutter codebase.

Build from source

git clone https://github.com/moradzadeh67/credo.git
cd credo
flutter pub get
flutter run -d macos

Requirements: Flutter 3.47.2, Dart 3.13.2, Android SDK 24+ for Android, Xcode for the Apple targets. You also need an OpenRouter API key — open the app and paste it in the setup screen. Full instructions are in the README.

Privacy in one line

Credo talks only to the OpenRouter API you configure. Your key is stored on your own device and never sent anywhere else. See docs/PRIVACY.md.
